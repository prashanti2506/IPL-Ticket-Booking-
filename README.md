# IPL 2026 Ticket Booking Website

A responsive IPL ticket booking website demo created as a student project using **HTML, CSS and JavaScript**.

## Features
- Responsive navigation and hero section
- IPL team and venue information
- Sample match schedule with team filter
- Ticket booking form with General, Premium and VIP categories
- Live booking summary and total price calculation
- My Bookings table populated after form submission
- Booking guidelines and footer

## Run the project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Important note
This is an educational front-end demonstration only. Match dates, teams and prices are sample data, not official IPL 2026 fixtures or ticket prices. It has no backend, database, payment gateway or real ticket issuing system. Bookings are kept only in the current page session and disappear after refreshing the page.

## Technologies
- HTML5
- CSS3
- JavaScript
